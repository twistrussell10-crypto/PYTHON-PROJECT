# 宠物品种分类器：汇报讲稿与答辩准备

适用场景：暑期 Python 课程，约 8–10 分钟。PPT 位于 `reports/宠物品种分类器_课程报告.pptx`，现场程序入口为项目根目录的 `start.bat`。

本材料依据本地训练记录、独立测试集评估结果和当前程序编写。此次界面与启动优化沿用已有模型，没有重新训练，也没有声称准确率提升。先按下面的讲稿练习一遍，再用自己的语言表达。

## 开场与任务范围（约 50 秒）

各位老师好，我汇报的项目是 Oxford-IIIT 宠物品种分类器。它是一个基于 Python 和 PyTorch 的深度学习项目，目标是输入一张宠物照片，输出最可能的品种，以及前五个候选结果。

项目识别数据集中规定的 37 个品种，包括 12 类猫和 25 类犬。它处理的是整张图片的品种分类。外观相似的猫犬可能只有脸型、耳朵、毛色或体型上的细微差异，所以这一任务比只区分猫和狗更难。

系统目前面向课程学习和本地演示，没有实现多宠物分别识别、混血判断或未知品种拒识。

## 数据与整体流程（约 80 秒）

数据使用 Oxford-IIIT Pet 的官方标注。官方 trainval 共 3,680 张，我们只在这部分内部，按品种分层划分 80% 训练集和 20% 验证集，分别得到 2,944 张和 736 张。官方测试集的 3,669 张图片单独保留。

这三个集合的用途不同：训练集让模型更新参数，验证集选择效果最好的轮次，测试集评价最终模型。代码保存了实际图片名单，并检查集合之间没有图片名重叠。这样可以避免把已经参与训练或模型选择的图片当成独立测试数据。

整体流程可以分成三条线。训练线是读取图片、进行预处理、更新模型并保存最佳权重；评估线是加载最佳权重，在官方测试集上生成指标和误分类分析；演示线是加载保存好的模型，对用户选择的一张图片进行预测。平时展示运行的是第三条线，不需要重新训练。

## 模型与训练方法（约 100 秒）

项目采用 ImageNet 预训练的 MobileNetV3-Large。迁移学习的意思是先利用模型已有的通用视觉特征，例如边缘、纹理和形状，再让它适应宠物品种任务。

代码保留预训练网络的特征提取部分，把最后的分类层替换成 37 类输出。替换后的模型共有 4,249,429 个参数，大约 425 万。这里的参数量对应本项目实际模型，不是原始 1,000 类分类器的参数量。

训练共进行 12 轮，分为两个阶段。前两轮冻结特征提取网络，只训练分类头，同时固定主干中 BatchNorm 的统计量。后十轮解冻主干，以更小的学习率微调整个网络。分类头第一阶段初始学习率为 0.001；微调阶段主干初始学习率为 0.0001，分类头为 0.0003。

训练采用交叉熵损失、AdamW 优化器、余弦学习率调整，批量大小为 32，随机种子为 42。训练图像使用随机裁剪、水平翻转和轻度颜色扰动；验证、测试和预测统一使用缩放、224×224 中心裁剪及 ImageNet 标准化，使输入规则保持一致。

## 学习曲线与测试成绩（约 90 秒）

从学习曲线可以看到，训练准确率持续提高，最后达到约 99.73%，但验证准确率主要在 90% 左右波动。这说明模型对训练数据的拟合很充分，同时存在训练和验证表现之间的差距，不能只看训练成绩。

本项目只依据验证准确率保存最佳模型。第 11 轮的验证准确率最高，为 92.12%；第 12 轮虽然训练准确率继续上升，但没有替换最佳模型。

在独立的官方测试集上，3,669 张图片中有 3,326 张第一名预测正确，343 张错误，因此 Top-1 准确率为 90.65%。Top-5 准确率为 99.37%，表示真实品种出现在前五个候选中。Macro F1 为 0.9055，它先分别计算各品种的 F1，再给每个品种相同权重取平均。

Top-5 较高说明候选列表有参考价值，但第一名的品种识别成绩仍应使用 Top-1 来描述。

## 错误分析与单图预测（约 70 秒）

错误主要可以从相似品种的混淆中观察。比如，美国比特斗牛梗被预测为斯塔福郡斗牛梗有 22 张，埃及猫被预测为孟加拉猫有 18 张。混淆矩阵的行是真实类别，列是预测类别，两个方向的错误数量不一定相同。

对于单图预测，模型首先输出 37 个分数，再经过 softmax 转换并按大小排序。示例中的比格犬图片，第一名比格犬的分数约为 94.20%，第二名巴吉度猎犬约为 5.77%。这是一张真实测试图片的结果，不能代替完整测试集成绩。

同时也有分数较高但预测错误的图片。示例 `Bengal_1` 的真实类别是孟加拉猫，却被预测为埃及猫，分数约为 91.69%。因此，当前 softmax 分数不能直接解释为真实正确概率，模型尚未做概率校准。

## 演示优化与文件组织（约 70 秒）

为了方便课堂展示，界面增加了中文品种名、前五名候选、预测 JSON 下载、品种搜索和实验结果查看。同一张图片在当前会话中的预测会复用，切换到搜索等操作时不需要重复运行模型。

启动器会检查依赖和训练模型，选择本机可用端口，等服务准备好后再打开浏览器。这样双击 `start.bat` 就能进入演示。

项目文件各司其职：Python 文件描述数据处理、训练和预测逻辑；`best.pt` 保存模型权重等推理所需信息；JSON 是便于程序读写的结构化记录。比如 `classes.json` 保存类别顺序，`config.json` 保存实验设置，`split.json` 保存划分名单，`metrics.json` 保存测试成绩及对应模型的指纹。JSON 文件通常不是展示时需要双击运行的入口。

## 现场演示（约 60 秒）

现在我双击项目目录下的 `start.bat`，进入图片识别页面。先选择比格犬示例，展示中文预测、英文类别和前五名候选；接着上传一张准备好的猫犬照片；然后进入实验结果，说明 90.65% 是完整官方测试集成绩；最后在支持的品种中搜索“比格”，展示类别范围。

预测结果可以下载成 JSON，实验报告也可以下载。展示过程中，模型只进行推理，不会修改已有权重。

## 局限与后续方向（约 50 秒）

当前结果来自一次固定随机种子的实验，没有通过多种子实验估计波动，也没有对所有真实拍摄环境进行验证。模型只从已知 37 类中选择；遇到数据集外的动物或物品时，也可能给出一个看似很高的分数。

后续可以重点研究相似品种的区分、概率校准和未知类别拒识，并增加不同光照、角度和背景的独立照片进行评估。新的超参数或模型应先用验证集选择，避免反复依据测试成绩调参。

通过这个项目，可以学习从数据划分、迁移学习到评估分析和应用展示的完整流程。以上是本次汇报，谢谢老师。

## 展示前的准备清单

1. 提前双击 `start.bat` 试运行一次，确认示例图能产生结果；需要排查时可运行 `.\.venv\Scripts\python.exe scripts\launch_app.py --check`。
2. 保留 `outputs/baseline/best.pt` 和项目 `.venv`。本地使用已有模型与示例图进行预测不需要下载数据。
3. 准备一张清楚、主体较完整的猫犬照片，提前试验，记住它只是现场演示样例。
4. 演示时保持启动终端打开；地址以终端显示的本地端口为准。结束后在终端按 `Ctrl+C`。
5. 在 PowerPoint 中打开报告，并使用演讲者视图阅读每页备注。若课堂时间紧，压缩训练细节，保留完整数据划分、独立测试结果和局限说明。
6. 换电脑时另行复制模型权重并安装环境。Git 仓库不包含数据、虚拟环境或模型权重。

## 六个常见答辩问题

### 1. 为什么选择 MobileNetV3，而不是从零开始训练？

本项目训练集只有 2,944 张图片，采用 ImageNet 预训练特征可以减少从小样本中学习通用视觉特征的压力。MobileNetV3-Large 的规模适合课程中的本地训练与 CPU 演示。本次没有进行从零训练或不同主干的对照实验，因此不能声称它在这些方案中最优。

### 2. 怎么证明测试数据没有参与训练？

训练代码只读取官方 `trainval`，在其中分层产生训练集和验证集，并把图片名单保存到 `split.json`。最佳轮次依据验证准确率选择。评估代码单独读取官方 `test`。本地检查验证了训练、验证、测试的图片名单互不重叠。这证明本项目管线按官方划分运行，但不等于对数据集中所有近似图片或预训练数据来源做了全面去重审计。

### 3. Top-1、Top-5 和 Macro F1 的区别是什么？

Top-1 看第一名预测是否正确，本次为 90.65%。Top-5 看真实品种是否进入前五个候选，本次为 99.37%。Macro F1 则综合各品种的精确率和召回率，再对 37 个品种等权平均，本次为 0.9055。它们反映不同角度，不能用 Top-5 替代第一名识别成绩。

### 4. 为什么训练准确率接近 100%，测试准确率却只有 90.65%？

训练数据会反复用于更新参数，而测试图片没有参与更新；模型可能学到更适合训练数据的特征，因此会存在泛化差距。训练增强、预训练和较小学习率有助于训练，但不能消除所有差距。本次通过验证集选择第 11 轮，而不是直接采用最后一轮；后续仍需要控制过拟合并做更充分的对照实验。

### 5. JSON 和 `.pt` 有什么区别？展示时运行哪一个？

JSON 主要保存人和程序都容易阅读的类别、配置、名单与结果。`.pt` 是 PyTorch checkpoint，保存数值权重，也包含本项目推理需要的类别顺序与预处理标识。展示时双击 `start.bat`，由启动器运行 `app.py` 并加载 `.pt`；无需直接运行 JSON。当前 checkpoint 面向推理，没有保存恢复训练所需的优化器状态。

### 6. 模型分数达到 99% 就一定正确吗？这次优化提高了多少准确率？

不一定。softmax 分数没有做概率校准，真实测试集中存在高分误分类；未知品种也会被强制分到已知类别。本轮工作优化了启动与演示交互，没有改变权重，所以不能声称准确率提高。报告沿用同一模型的官方测试成绩：Top-1 90.65%、Top-5 99.37%。
